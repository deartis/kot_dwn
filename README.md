### Como instalar ou atualizar

1. Abra o link acima no celular e baixe o arquivo APK.
2. Abra o arquivo baixado. Se o Android solicitar, permita que o navegador instale o aplicativo.
3. Conclua a instalação e abra o app.
4. *Já possui uma versão anterior instalada?* Basta baixar o APK e instalar por cima para atualizar com todos os seus dados preservados.

## Novidades da Build 28

- **🎲 Calibração de Escassez e Trilha Vazia (60% Null):**
  - **Madeira Bruta:** `20%` (recurso básico da trilha para marcenaria e obras)
  - **Pedra Bruta:** `15%` (material estrutural para fundações e muralhas)
  - **Minério Bruto:** `5%` (**raro!** metal pesado para fundição e armaduras)
  - **Trilha Vazia (`null`):** `60%` (preserva o valor dos materiais e impede inflação na mochila)
- **🎒 Transparência na Mochila (`InventoryScreen`):**
  - Adicionado chip visual explicativo informando a probabilidade de 60% de trilha vazia por intervalo de 250m.
- **☁️ Sincronização com a API na VPS:**
  - Banco de dados em produção configurado com os novos padrões de escassez da Season 1.
